# dsh-livevoice 0.1.6

Enable public npm publication, include the declared TypeScript entry points, and update installation instructions for official DSH 0.2.0-rc.2.

Runtime code is unchanged from the preceding GitHub release.

The npm distribution uses `@aa2246740/dsh-livevoice` because the registry reserves the unscoped name as too similar to an existing package. Install with `dsh-livevoice@npm:@aa2246740/dsh-livevoice@0.1.6` to preserve the bundled module ID.
