# dsh-livevoice 0.1.5

## DeepSeek Harness compatibility

Built and tested against DeepSeek Harness `0.2.0-rc.2` (`639ed015397290b3745d163aafe02ffee4aa3f84`). Use the prebuilt release package or this repository’s compiled artifacts with the official plugin installer.

General settings now includes a local microphone check. It verifies capture and stops every track without connecting to a model or uploading audio.

Validation was performed on macOS arm64. This release does not claim new Windows or Linux runtime acceptance.
